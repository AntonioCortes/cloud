Declarative Pipelines Avanzados

Un `Jenkinsfile` declarativo es mucho más que definir `stages` y `steps`. Para dominarlo, necesitas dominar la inyección de entorno, los parámetros dinámicos y la ejecución condicional.

Opciones, Entornos y Parámetros


pipeline {
    agent any
    
    options {
        buildDiscarder(logRotator(numToKeepStr: '10')) // Evita llenar el disco
        timeout(time: 1, unit: 'HOURS') // Aborta si se cuelga
        disableConcurrentBuilds() // Evita race conditions
    }

    environment {
        // Variables globales
        AWS_REGION = 'eu-west-1'
        // Extraer un secreto del gestor de credenciales de Jenkins
        DB_PASS = credentials('db-password-id')
    }

    parameters {
        choice(name: 'ENTORNO', choices: ['dev', 'staging', 'prod'], description: 'Destino')
        booleanParam(name: 'RUN_TESTS', defaultValue: true)
    }

    stages {
        stage('Deploy') {
            // Ejecución condicional (When)
            when {
                expression { params.ENTORNO == 'prod' }
                branch 'main'
            }
            steps {
                echo "Desplegando en Producción usando ${env.AWS_REGION}..."
            }
        }
    }
}

El Bloque When: Es fundamental para la lógica de negocio. Permite saltarse fases enteras si no se cumplen ciertas condiciones (por ejemplo, si no estamos en la rama `main` o si el parámetro de entorno no es `prod`), ahorrando minutos valiosos de computación.
