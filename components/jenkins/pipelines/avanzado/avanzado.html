Pipelines Avanzados

Una vez dominas el Pipeline Declarativo básico, Jenkins te ofrece herramientas muy poderosas para escalar y reutilizar tu código en infraestructuras masivas.

Scripted Pipelines

Mientras que el modelo "Declarativo" es estricto y estructurado, existe otro formato llamado "Scripted Pipeline". Este te permite escribir código Groovy libre y usar bucles for, sentencias if/else complejas y manejar excepciones libremente.


// Ejemplo de Scripted Pipeline
node('linux') {
    stage('Build dinámico') {
        def envs = ['dev', 'staging', 'prod']
        for (e in envs) {
            echo "Desplegando en ${e}"
        }
    }
}

Shared Libraries (Librerías Compartidas)

Si tienes 50 repositorios y todos compilan una app de Node.js de la misma forma, no copies el mismo Jenkinsfile 50 veces. Crea una Shared Library (un repositorio Git separado de Jenkins) con una función global llamada buildNodeJS() y úsala en todos tus pipelines con una sola línea de código.

El bloque Post

¿Quieres que te avise por Slack si falla la compilación? El bloque post se añade al final de un Pipeline Declarativo y reacciona al estado final de la ejecución:


pipeline {
    agent any
    stages { /* ... */ }
    post {
        success {
            echo '¡El pipeline pasó con éxito!'
        }
        failure {
            echo '¡El pipeline falló!'
            // slackSend channel: '#alertas', message: 'Fallo en Producción'
        }
        always {
            echo 'Esto se ejecuta pase lo que pase (ideal para limpieza)'
        }
    }
}
