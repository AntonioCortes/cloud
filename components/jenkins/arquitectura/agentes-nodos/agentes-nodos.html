Agentes y Nodos

A medida que tu equipo crece, Jenkins tendrá que ejecutar muchos pipelines a la vez. Si el servidor maestro (el que aloja la interfaz web) se encarga de compilarlos todos, colapsará rápidamente. Por ello, Jenkins utiliza una arquitectura distribuida.

Rol Responsabilidad
Master (Control Plane) Sirve la interfaz web, planifica los jobs, y monitoriza los agentes. ¡Nunca ejecutes compilaciones pesadas aquí!
Agent / Node (Worker) Máquinas conectadas al Master (Linux, Windows, o Contenedores Docker efímeros) que hacen el trabajo duro.
La regla de oro: Mantén el Master ligero

Asignación de carga de trabajo

Cuando escribes tu Pipeline, puedes decirle a Jenkins que ejecute todo el pipeline o solo una fase en un nodo específico usando etiquetas (labels).


pipeline {
    // Escoger un nodo Linux que tenga Docker instalado
    agent { label 'linux && docker' }

    stages {
        stage('Build iOS App') {
            // Este stage específico correrá en un nodo MacOS
            agent { label 'macos' }
            steps {
                sh 'xcodebuild'
            }
        }
    }
}
