Arquitectura Experta de Nodos

En el nivel básico, conectas máquinas estáticas (Linux o Windows) a Jenkins vía SSH o JNLP. Pero en una arquitectura Cloud-Native "0 to Hero", los agentes estáticos son un antipatrón (desperdician dinero cuando están inactivos). La solución son los Agentes Efímeros.

Agentes Dinámicos con Docker y Kubernetes

Jenkins puede integrarse con el API de Docker o Kubernetes para crear contenedores al vuelo en el momento en que se solicita un build, y destruirlos instantáneamente al terminar.

Ventaja de Agentes Efímeros Explicación
Aislamiento Absoluto Cada build se ejecuta en un contenedor virgen. No hay problemas de "funcionaba en mi máquina" ni basura temporal residual de builds anteriores.
Cero Mantenimiento No tienes que actualizar Java, Node, o Go en los agentes de Jenkins. Simplemente descargas la imagen oficial en tu Pipeline.
Beneficios de la elasticidad computacional

Sintaxis de Agente Docker


pipeline {
    // Jenkins levanta este contenedor, inyecta tu código, ejecuta los steps, y lo destruye.
    agent {
        docker { 
            image 'node:18-alpine' 
            args '-v /tmp/cache:/root/.npm' // Caché de dependencias
        }
    }
    stages {
        stage('Build') {
            steps {
                sh 'npm ci && npm run build'
            }
        }
    }
}
