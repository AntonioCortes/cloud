Instalación y Configuración

La forma más moderna, limpia y recomendada para principiantes de probar Jenkins es ejecutarlo como un contenedor Docker. De esta forma, no instalas dependencias pesadas en tu sistema host como Java o herramientas de construcción.

Ejecutar Jenkins con Docker

Abre una terminal y ejecuta el siguiente comando. Esto descargará la imagen recomendada y la ejecutará exponiendo el puerto 8080:


docker run -p 8080:8080 -p 50000:50000 --restart=on-failure -v jenkins_home:/var/jenkins_home jenkins/jenkins:lts-jdk17
Parámetro Explicación
-p 8080:8080 Mapea el puerto de la interfaz web para que puedas acceder desde tu navegador.
-p 50000:50000 Puerto usado para que los agentes JNLP (esclavos) se conecten al master.
-v jenkins_home... Crea un volumen persistente para que no pierdas tu configuración si el contenedor se apaga.
Desglose del comando Docker

El Asistente Inicial (Wizard)

Al acceder por primera vez a http://localhost:8080, Jenkins estará bloqueado. Te pedirá una contraseña inicial que verás impresa en los logs de la terminal de Docker.

  • Copia y pega la contraseña inicial de los logs.
  • Selecciona "Install suggested plugins". Esto descargará Git, Pipeline y otras herramientas esenciales automáticamente.
  • Crea tu primer usuario administrador y empieza a usar Jenkins.
