Networking

El sistema de redes (networking) de Docker permite a los contenedores comunicarse entre sí de forma segura, o con el mundo exterior.

Tipo de Red Descripción
bridge La red por defecto. Los contenedores en la misma red bridge pueden comunicarse, pero no tienen resolución DNS por nombre de contenedor a menos que sea una red bridge personalizada.
host El contenedor usa directamente la interfaz de red del anfitrión. Elimina el aislamiento de red (solo Linux).
none Aísla completamente el contenedor de cualquier red.
Controladores de red principales

Creando Redes Personalizadas

Se recomienda encarecidamente crear redes bridge personalizadas, ya que proporcionan resolución DNS automática entre contenedores.


# Crear una red llamada mi-red
docker network create mi-red

# Levantar contenedores adjuntos a esta red
docker run -d --name mi-backend --network mi-red backend:1.0
docker run -d --name mi-frontend --network mi-red -p 80:80 frontend:1.0
El frontend ahora puede comunicarse con el backend haciendo ping a mi-backend.
