Introducción a Docker

Docker es una plataforma abierta diseñada para desarrollar, enviar y ejecutar aplicaciones. Te permite separar tus aplicaciones de tu infraestructura, lo que significa que puedes entregar software rápidamente.

La analogía: Contenedores vs. Máquinas Virtuales

Para entender Docker, es útil compararlo con la virtualización tradicional (Máquinas Virtuales o VMs).

Característica Máquinas Virtuales (VM) Contenedores Docker
Aislamiento Aislamiento total de hardware mediante un Hypervisor. Aislamiento de procesos a nivel del sistema operativo.
Sistema Operativo (OS) Cada VM incluye un SO Invitado (Guest OS) completo, ocupando GBs. Comparten el kernel del SO Anfitrión (Host OS), son ligeros.
Arranque Minutos (requiere arrancar un SO entero). Milisegundos o Segundos (es solo un proceso).

Arquitectura Cliente-Servidor

  • Docker Client: La línea de comandos que utilizamos para mandar instrucciones (como docker run).
  • Docker Daemon (dockerd): El servicio pesado que corre en segundo plano y hace el trabajo duro de construir, correr y distribuir contenedores.
  • Docker Registry: El almacén de imágenes (como Docker Hub), desde donde descargamos las aplicaciones empaquetadas.
