Contenedores

Un contenedor es una unidad estándar de software que empaqueta código y todas sus dependencias para que la aplicación se ejecute de forma rápida y confiable de un entorno informático a otro. Es esencialmente una instancia en ejecución de una imagen de Docker.

Ciclo de Vida de un Contenedor

  • Created (Creado): El contenedor se ha preparado pero aún no está corriendo.
  • Running (En ejecución): El proceso principal del contenedor está activo.
  • Paused (Pausado): Todos los procesos del contenedor están congelados temporalmente.
  • Stopped/Exited (Detenido): El proceso ha terminado o se ha forzado su finalización.

Comandos Básicos de Consola

Para crear y arrancar un contenedor nuevo (si la imagen no existe localmente, se descargará primero):


docker run -d --name mi-servidor -p 8080:80 nginx
El flag -d lo corre en segundo plano (detached), y -p mapea el puerto 8080 local al 80 del contenedor.

Para ver los contenedores que están actualmente en ejecución:


docker ps

Para detener un contenedor activo de forma segura:


docker stop mi-servidor

Para eliminar un contenedor (debe estar detenido, o usar el flag -f para forzarlo):


docker rm mi-servidor
