Seguridad en Docker

Garantizar la seguridad de tus contenedores es vital para prevenir intrusiones en tu infraestructura.

Buenas Prácticas Clave

  • Principio de Mínimo Privilegio: Nunca ejecutes la aplicación interna del contenedor como el usuario root. Crea y usa un usuario sin privilegios en tu Dockerfile.
  • Imágenes Ligeras y Oficiales: Usa imágenes base verificadas (Oficiales de Docker Hub) y prefiere distribuciones minimalistas como Alpine o imágenes Distroless para reducir la superficie de ataque.
  • No filtres secretos: No copies contraseñas ni claves API en el Dockerfile. Usa herramientas como Docker Secrets o inyéctalas en tiempo de ejecución.

Ejemplo: Usuario sin privilegios


FROM node:18-alpine

# Crear directorio y asignar permisos al usuario node que viene en la imagen
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .

# Cambiar al usuario sin privilegios 'node'
USER node

EXPOSE 3000
CMD ["npm", "start"]

Escaneo de Vulnerabilidades

Revisa tus imágenes en busca de CVEs (Vulnerabilidades Comunes) antes de desplegarlas:


docker scout cves mi-app:1.0
