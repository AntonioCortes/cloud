Almacenamiento y Volúmenes

Por defecto, los datos creados dentro de un contenedor son efímeros; si el contenedor se destruye, los datos se pierden. Para persistir datos, Docker ofrece diferentes mecanismos.

Tipo Características
Volumes Totalmente gestionados por Docker. Es la mejor opción para persistir bases de datos.
Bind Mounts Mapean una ruta exacta de tu sistema anfitrión (host) dentro del contenedor. Muy útiles en desarrollo.
tmpfs Almacenamiento en memoria RAM. Rápido pero se borra al detener el contenedor.
Tipos de almacenamiento persistente

Uso de Volúmenes

Crear un volumen nombrado gestionado por Docker:


docker volume create mi-volumen-db

Lanzar un contenedor adjuntando ese volumen a la ruta interna de datos:


docker run -d --name mi-bd -v mi-volumen-db:/var/lib/mysql mysql:8

Limpiar volúmenes huérfanos que ya no están asociados a ningún contenedor:


docker volume prune
