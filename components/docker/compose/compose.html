Docker Compose Avanzado

Docker Compose es la herramienta estándar para declarar la infraestructura como código en entornos de desarrollo y pruebas. Un experto no se limita a levantar contenedores, sino que orquesta sus dependencias, estado de salud y redes complejas.

Control de Flujo con Healthchecks

El clásico problema de levantar una base de datos y un backend al mismo tiempo es que el backend arranca más rápido e intenta conectarse a la DB antes de que esta termine de inicializarse, provocando un CrashLoop. La directiva depends_on básica no soluciona esto; necesitas usar healthchecks.


version: '3.8'
services:
  backend:
    image: mi-api:1.0
    depends_on:
      db:
        condition: service_healthy # Espera a que el healthcheck pase

  db:
    image: postgres:14
    environment:
      - POSTGRES_PASSWORD=secreta
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5
El backend solo arrancará cuando postgres confirme que acepta conexiones

Perfiles (Profiles) y Variables de Entorno

Puedes usar el mismo docker-compose.yml para desarrollo y pruebas (mocking) usando Profiles y cargando secretos dinámicamente desde un archivo .env sin subirlos a Git.


services:
  frontend:
    image: mi-frontend
    environment:
      - API_URL=${API_URL:-http://localhost:8080} # Fallback por defecto

  debug-tools:
    image: adminer
    profiles:
      - debug # Solo se levanta si ejecutas: docker compose --profile debug up
