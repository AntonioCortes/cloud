Orquestación Local: Docker Compose

A menudo, una aplicación moderna no consiste en un único contenedor, sino en múltiples servicios que necesitan comunicarse (por ejemplo, un backend, una base de datos y un frontend). Docker Compose es una herramienta para definir y ejecutar aplicaciones multi-contenedor.

Infraestructura como Código

Con Compose, utilizas un archivo YAML para configurar los servicios de tu aplicación. Esto permite que con un solo comando puedas crear y arrancar todos los servicios de tu configuración.


version: '3.8'

services:
  web:
    image: nginx:latest
    ports:
      - "80:80"
    depends_on:
      - api

  api:
    image: mi-backend-api:1.0
    environment:
      - DB_HOST=db
    ports:
      - "3000:3000"

  db:
    image: postgres:13
    environment:
      - POSTGRES_USER=admin
      - POSTGRES_PASSWORD=secreta
    volumes:
      - db-data:/var/lib/postgresql/data

volumes:
  db-data:
docker-compose.yml declarando una red interna con Nginx, un backend y PostgreSQL

Comandos Clave

Para levantar toda la infraestructura definida en el YAML en segundo plano:


docker-compose up -d

Para detener y eliminar todos los contenedores y redes creadas por compose:


docker-compose down
