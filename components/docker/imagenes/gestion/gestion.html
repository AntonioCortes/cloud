Gestión Avanzada de Imágenes

A medida que construyes y descargas contenedores, las imágenes pueden consumir rápidamente todo el disco de tu servidor. La gestión experta no solo trata de borrar, sino de entender el árbol de imágenes y optimizar el almacenamiento.

Dangling Images (Imágenes Colgantes)

Cuando construyes una imagen con la etiqueta `mi-app:latest` y luego haces cambios y vuelves a construirla con la misma etiqueta, la imagen anterior no se borra. Pierde su nombre y se convierte en una dangling image (mostrada como `<none>:<none>`).


# Elimina todas las dangling images de forma segura
docker image prune

# Elimina TODA imagen que no esté en uso por un contenedor (¡Cuidado!)
docker image prune -a

Exportar e Importar (Air-gapped environments)

En servidores de máxima seguridad sin conexión a Internet (air-gapped), no puedes hacer `docker pull`. Un experto sabe cómo mover imágenes físicamente mediante archivos comprimidos (tarballs).


# Servidor con Internet: Exporta la imagen a un archivo .tar
docker save -o ubuntu_image.tar ubuntu:latest

# Servidor Air-gapped: Carga la imagen desde el archivo .tar
docker load -i ubuntu_image.tar
