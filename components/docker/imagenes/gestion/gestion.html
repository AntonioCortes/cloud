Gestión de Imágenes

Administrar las imágenes almacenadas localmente es crucial para no llenar el disco duro de tu servidor o máquina local.

Comandos de Gestión

Listar todas las imágenes descargadas o construidas localmente:


docker images

Inspeccionar los metadatos completos de una imagen (variables de entorno, arquitectura, capas):


docker inspect nginx:latest

Eliminar una imagen específica por su nombre o ID:


docker rmi nginx:latest

Limpieza Profunda (Pruning)

Con el tiempo, al construir nuevas imágenes, se generan "dangling images" (imágenes colgantes que ya no tienen etiqueta). Para liberar espacio de forma segura, ejecuta:


docker image prune
Añadir el flag -a eliminará toda imagen que no esté siendo usada por un contenedor.
