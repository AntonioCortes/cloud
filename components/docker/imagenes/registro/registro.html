Registro de Imágenes

Un Docker Registry es un sistema de almacenamiento y distribución de imágenes. Docker Hub es el registro público por defecto, pero puedes configurar registros privados (como AWS ECR o Harbor).

Distribución de Imágenes

Descargar una imagen desde el registro público:


docker pull ubuntu:20.04

Antes de subir tu propia imagen, necesitas autenticarte en el registro:


docker login

Para subir una imagen, primero debes etiquetarla (tag) con tu nombre de usuario o la URL del registro privado:


# Renombrar/Etiquetar
docker tag mi-app:1.0 mi-usuario/mi-app:1.0

# Subir al registro
docker push mi-usuario/mi-app:1.0
