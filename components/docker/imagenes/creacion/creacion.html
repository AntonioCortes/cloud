Creación de Imágenes: Dockerfile

Una imagen de Docker es una plantilla de solo lectura que contiene un conjunto de instrucciones para crear un contenedor. A diferencia del contenedor, la imagen es inmutable. Se compone de múltiples capas (layers) que se apilan unas sobre otras. Solo la última capa, creada al arrancar el contenedor, es de lectura y escritura.

El archivo Dockerfile

El Dockerfile es un archivo de texto simple que contiene todas las instrucciones paso a paso para construir una imagen.


# Usar una imagen oficial de Node.js ligera como base
FROM node:18-alpine

# Establecer el directorio de trabajo dentro de la imagen
WORKDIR /app

# Copiar el archivo package.json al directorio de trabajo
COPY package*.json ./

# Ejecutar el comando para instalar dependencias
RUN npm install

# Copiar el resto del código fuente a la imagen
COPY . .

# Exponer el puerto en el que escucha la aplicación
EXPOSE 3000

# El comando por defecto a ejecutar cuando el contenedor inicie
CMD ["npm", "start"]
Ejemplo típico de Dockerfile para una app Node.js

Para construir la imagen a partir de este archivo, usamos el comando docker build:


# El punto final indica que busque el Dockerfile en el directorio actual
docker build -t mi-app-node:1.0 .
