Orquestación: Docker Swarm

Mientras que Docker Compose es excelente para orquestar contenedores en una única máquina, cuando necesitas escalar tu aplicación a través de múltiples servidores (un clúster), necesitas una herramienta de orquestación más avanzada. Docker Swarm es el orquestador nativo integrado directamente en el Docker Engine.

Arquitectura de Swarm

  • Nodos Manager: Mantienen el estado del clúster, planifican los servicios y sirven la API de Swarm.
  • Nodos Worker: Reciben y ejecutan tareas (contenedores) asignadas por los Managers.

Comandos Básicos de Swarm

Para inicializar un nuevo clúster Swarm (esto convierte la máquina actual en el primer Manager):


docker swarm init

Para listar los nodos que forman parte del clúster:


docker node ls

Para crear un servicio replicado a lo largo del clúster:


docker service create --replicas 3 --name mi-web nginx
