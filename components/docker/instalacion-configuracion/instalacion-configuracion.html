Instalación y Configuración

Existen dos formas principales de instalar Docker dependiendo del sistema operativo y las necesidades: Docker Engine y Docker Desktop.

Opción Descripción Plataformas
Docker Engine La versión nativa de código abierto. Solo incluye el demonio y la CLI. Ideal para servidores. Linux
Docker Desktop Aplicación con interfaz gráfica. Incluye una máquina virtual ligera para correr el demonio en SO no nativos. Windows, macOS, Linux
Opciones de Instalación

Instalación en Linux (Ubuntu/Debian)

Para instalar la versión nativa de Docker Engine, se suelen usar los repositorios oficiales:


# Actualizar e instalar dependencias
sudo apt-get update
sudo apt-get install ca-certificates curl

# Añadir la clave GPG oficial de Docker
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Instalar Docker Engine
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

Verificación

Para confirmar que la instalación ha sido exitosa y el demonio está corriendo:


docker --version
docker info
