Instalación Avanzada y Configuración

Instalar Docker parece sencillo (un simple instalador o `apt-get`), pero entender su arquitectura interna es lo que te diferencia de un principiante. Docker funciona bajo un modelo Cliente-Servidor comunicándose a través de un socket UNIX.

Arquitectura del Demonio

En Linux, el cliente (la CLI `docker`) se comunica con el demonio (dockerd) a través de `/var/run/docker.sock`. Este archivo es sumamente poderoso: cualquier usuario con acceso a este socket tiene permisos equivalentes a `root` en la máquina anfitriona.


# Instalación recomendada en servidores de producción (Linux)
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Añadir tu usuario al grupo 'docker' para no usar sudo (CUIDADO: Equivale a root)
sudo usermod -aG docker $USER

El archivo daemon.json

Para configuraciones avanzadas a nivel de servidor (como configurar DNS personalizados, proxies o rotación automática de logs), no usamos parámetros en la consola. Editamos el archivo /etc/docker/daemon.json.


{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  },
  "default-address-pools": [
    {"base": "10.200.0.0/16", "size": 24}
  ]
}
Ejemplo: Limitando los logs para que no llenen el disco duro y cambiando la subred por defecto.
